# COSC 2360: Web Page Dynamics and Scripting

Welcome to the course repository. This is your workspace for the three programming projects in COSC 2360. Everything you build this term happens here.

## How this repository works

You made your own copy of this repository during the Week 1 setup, and you cloned it into the cloud VS Code environment. Each week you build that week's milestone in the matching project folder, then save your work back to GitHub and submit your repository link in Canvas.

You write your code in each project's `script.js` file. The `index.html` and `styles.css` in every project are already built for you, so you can focus on the JavaScript. Do not rename these files, because the HTML links to the CSS and JavaScript by name, and they must stay together in the same folder.

## The everyday Git workflow

After you make changes, save your work to GitHub with these commands in the terminal:

```
git status
git add .
git commit -m "Describe what you did, for example: Week 2 tip and total"
git push
```

Commit and push often. Each commit is a checkpoint you can return to, and your Canvas submission is the link to your repository, so make sure your latest work is pushed before the deadline.

## What is in this repository

- `project-1-tip-split-calculator/` : Project 1, Weeks 1 to 4. A calculator for the tip, total, and each person's share of a bill.
- `project-2-task-board/` : Project 2, Weeks 5 to 8. An interactive task manager you can add to, search, sort, and check off.
- `project-3-live-data-dashboard/` : Project 3, Weeks 9 to 12. A weather dashboard that pulls live data from a free public service.

Each project folder contains:

- `index.html` : the page structure, already built.
- `styles.css` : the styling, already built.
- `script.js` : where you write your code, with a section and hints for each week.
- `README.md` : the project goal, how to run it, the element ids you will use, and the milestone list.

## Working on a project

1. Open the project folder for the current week.
2. Open `index.html` in the browser preview to see the page.
3. Write your code in `script.js`, saving and refreshing the preview as you go.
4. Use the browser developer tools (Console tab) to see messages and find errors.
5. Commit and push your work, then submit your repository link in Canvas.

## Getting help

Each week's module in Canvas lists free resources that explain that week's ideas in different ways. When something does not click, start with the resource listed for that week. And if you are stuck for more than a little while, reach out early. A short question early saves hours later.
